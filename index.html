使用方法04 / HOW

四步上手

  1. 注册账号使用邮箱注册希儿云（Seele）会员账号，设置好密码即可。
  2. 选择套餐在订阅页面选择基础版、旗舰版或团队版，按月或按年付款。
  3. 下载客户端前往“客户端下载”区块，按系统选择对应版本并安装。
  4. 导入节点一键连接登录客户端后，系统会自动同步你的可用节点，点击连接即可开始使用。

使用小贴士

  1. 节点切换遇到卡顿时，先在客户端里换一个节点，不必反复重启软件。
  2. 多设备同时登录的设备数请按所选套餐的额度控制，超出会被提示降速。
  3. 流量计算会员中心首页会显示本月已用 / 剩余流量，建议每月看一眼。
  4. 问题反馈无法解决时，可提交工单，旗舰版与团队版会优先响应。

常见问题06 / FAQ

下面整理了订阅前后最常被问到的问题。如果看完仍有疑问，欢迎在会员中心提交工单。

希儿云（Seele）是按月收费吗？会自动续费吗？

是的，希儿云默认按月收费。我们不会默认开启自动续费，订单页会清楚写明本次订阅的到期时间，到期前 3 天会发送提醒邮件。如果你想要更划算的年付方案，也可以在订阅页面手动选择。

三档套餐分别适合谁？我该怎么判断？

基础版适合一个人偶尔用用、看看网页和轻度视频；旗舰版是大多数用户的日常选择，覆盖办公、追剧和偶尔游戏；团队版面向小型工作室或家庭共用的场景，设备数和流量都更大。如果你不确定，可以先从基础版或旗舰版开始，后续在会员中心一键切换。

新用户有试用吗？怎么领取？

新用户首次注册账号后，可以在会员中心首页看到“体验时长”入口，按页面提示完成邮箱验证即可领取。试用时长和可用节点以页面公示为准，到期后不会自动扣费。

流量用完了会怎样？会额外收费吗？

当月流量用完后，连接速度会被限制，客户端会提示“本月额度已用完”，不会产生任何额外扣费。下个月额度恢复后会自动恢复速度，也可以在会员中心单独购买流量加油包。

支持哪些设备和系统？

目前提供 Windows、macOS、iOS、Android 客户端，以及面向路由器和电视端的方案。具体系统版本要求请参考“客户端下载”区块的说明。

节点不稳定怎么办？

建议先在客户端里手动切换到其他节点；如果多个节点都不理想，请记录下大致时间与地区，并在会员中心提交工单，我们会协助排查。旗舰版与团队版享有优先响应。

可以同时登录几台设备？

同时登录的设备数与所选套餐挂钩：基础版 3 台、旗舰版 5 台、团队版 20 台。超出后最早登录的设备会被自动踢下线，登录页会提示已达上限。

如何申请退款？

如果你在订阅后觉得不合适，可以在会员中心提交退款申请，按页面提示说明原因。我们会在工单里回复处理结果。请注意，流量加油包等单项加购不在默认退款范围内。

希儿云会保存我的使用日志吗？

我们仅保留维持服务所必需的最少记录，例如登录状态、流量计数与必要的风控数据。我们不会出售或与第三方共享你的账号信息。详细说明请查阅会员中心的服务条款页面。

如何联系客服？

最直接的渠道是会员中心的工单系统，请提供账号、订单号和具体问题描述，附上截图会帮助我们更快定位。旗舰版与团队版会获得更快的响应。
